# Release status

Current status: **Candidate** — E2E fine-tuning tutorial source complete, awaiting supported clean-runtime execution. The pipeline package (inference contract, digest-pinned SciTLDR-A corpus, ROUGE-1/2/L with Lead baselines, bounded decoder fine-tuning, safetensors adapter), 34 offline unit tests plus 5 notebook-parity tests and 2 model-backed tests, one executed local CPU run of the committed notebook blob, the MODEL_CARD_SPEC 1.1 `MODEL_CARD.md`, and the standalone `E2E` tutorial `tutorials/bart_summarization_colab.ipynb` (generated by `tools/build_notebook.py`, DIMER Notebook Specification 2.0 §4) exist and pass static validation (`tools/validate_release_assets.py`, including the generator parity checks). Unit tests and static conformance checks run in GitHub Actions. The tutorial remains non-release-grade until clean-runtime execution evidence from a supported hosted runtime for the exact candidate commit is recorded according to `docs/release-verification.md`.

No hosted run of the earlier `TASK-INFERENCE` notebook was ever recorded (it was queued to the GPU lane); the `E2E` notebook replaces it and starts its own evidence trail.

No licence or remote-code gate is open for DIMER hosting (MIT weights; safetensors; `trust_remote_code=False`). The adaptation sample is fetched at run time from the pinned `allenai/scitldr` commit (SciTLDR-A, Apache-2.0, three JSON-Lines files, 5.5 MB) and is not redistributed by this repository. Two behaviours worth a reviewer's eye: every ROUGE number is produced under explicit TL;DR-length generation settings (`max_new_tokens` 48, `min_new_tokens` 0) rather than the pinned news defaults, which force at least 55 tokens; and the adapter writes one short sentence for any input, trading away the base model's news-highlight behaviour — the card, notebook and README say so. CPU time for the default path is about twelve minutes on the build workstation and will be longer on a hosted CPU runtime.
